# ADR 0001: サーバーセッション認証を採用する

- 状態: 採用
- 日付: 2026-10-28

## 背景

Web（Next.js）と API（Go）を同一オリジンで配信する（`/api/*` を API へ振り分け）。
学習者には保護者配下の子どもプロファイルが含まれ、退会・端末紛失時に即時失効できる必要がある。

## 決定

- MariaDB の `sessions` テーブルにセッションを保存する。トークンは 256bit 乱数、DB にはその SHA-256 のみ保存。
- Cookie: `HttpOnly; Secure; SameSite=Lax; Path=/`。
- 状態変更リクエストは `Origin` ヘッダー検証で CSRF を防ぐ。
- パスワードは argon2id。

## 却下した案

- **JWT（アクセス＋リフレッシュ）**: Cookie に入れる以上ステートレスの利点がなく、失効・ローテーションの実装負担だけが残る。

## 影響

- リクエストごとにセッション参照が 1 回発生する。負荷が問題になれば読み取りキャッシュを後付けする。

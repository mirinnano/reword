# ReWord（仮称）開発計画

英検 準2級〜1級 向けのデジタル学習サービス。1 名開発、製品リリース前提、初期は無料枠中心で運用する。

## 前提

| 項目 | 決定 |
|---|---|
| 対象 | 個人向け（B2C）。保護者アカウントの下に子どもの学習者を作れる |
| 対象級 | 準2級・準2級プラス・2級・準1級・1級（スキーマは5級〜1級まで対応） |
| 開発体制 | 1 名 |
| 問題の調達 | LLM で下書き → 監修 → TTS で音声化（オリジナル問題のみ。過去問は使わない） |
| ホスティング | 無料枠中心 → 負荷に応じて AWS へ（[ADR 0003](adr/0003-free-tier-hosting.md)） |
| 名称 | 「ReWord」は仮称（Key 作品『Rewrite』から着想）。商標調査後に確定 |

## 1 名体制による優先順位

- **コンテンツが最大のボトルネック。** 5 級分を一度に揃えるのは非現実的なので、リリースは級ごとに段階的に行う。
  - 順序案: 2級 → 準2級／準2級プラス → 準1級 → 1級（1級は語彙・作文とも監修の難度が最も高い）
- 自分で運用しなくて済む部分（CDN・ストレージ・メール・エラー監視）は外部サービスに任せる。
- 自前で運用するのは VM 1 台（API・Worker・MariaDB）だけに絞る。

## アーキテクチャ

```
ブラウザ ── Cloudflare（DNS / CDN / WAF）
              ├─ /api/*  → Cloudflare Tunnel → VM: Go API ─┐
              └─ その他  → Workers: Next.js（OpenNext）     │
                                                           ├─ MariaDB（同 VM）
                          VM: Go Worker（TTS・メール・集計）─┘
              R2: 音声・画像・DB バックアップ
```

## 技術選定

| 領域 | 採用 |
|---|---|
| API | Go 1.27、chi、slog、機能ごとのパッケージ |
| DB アクセス | sqlc（制約付き、[ADR 0002](adr/0002-sqlc-with-mariadb.md)）、golang-migrate |
| 認証 | MariaDB セッション＋httpOnly Cookie＋Origin 検証（[ADR 0001](adr/0001-session-auth.md)） |
| ジョブ | MariaDB テーブル＋`FOR UPDATE SKIP LOCKED` |
| Web | Next.js 16（App Router）。紹介ページは静的生成、学習画面はクライアント側＋TanStack Query |
| API 契約 | OpenAPI。TS 側の型のみ生成（openapi-typescript） |
| 単語学習 | FSRS＋復習履歴の保存 |
| 監視 | Sentry、構造化ログ、外形監視 |

## データモデル（主要部分）

- **アカウント**: `users`、`learner_profiles`、`sessions`、`consents`
- **試験構造**: `grades`（作成済み）、`question_types`
- **コンテンツ**（公開後は編集せず、新しい版を作る）: `questions`（`stable_key`＋`version`、`format`、`payload_json`、`answer_json`、`status`）、`assets`、`content_reviews`
  - 長文は別テーブルにせず、設問ごとの `payload` に本文を持たせる（設問の版が、解いた時点の本文も固定する）
- **学習**: `attempts`（サーバー側の締切時刻）、`attempt_items`（問題の版を固定）、`responses`
- **単語**: `vocab_items`、`vocab_cards`、`review_logs`
- **運用**: `jobs`（作成済み）、`audit_logs`、`subscriptions`、`stripe_events`

スコアは正答率と合格ラインの目安のみ表示し、CSE スコアの換算は出さない。

## 日課と復習の規則

毎日の日課は 12 問で、語彙・熟語と単語ドリルを混ぜ、2 回に 1 回は長文を 1 題入れる（長文の設問も 12 問に含む）。単語の逆向きドリル（`vocab_word`）は日課に入れず、形式別の演習でだけ出す。

復習は誤答を優先し、1、4、10、30、90 日の間隔で戻す。初めて見た問題に正解したら 7 日後に戻す。習得は間隔をあけた 3 回連続の正解で、間隔の段階とは別に数える。

新規の枠は、復習待ちが 1 回分以下なら 3 分の 1、2 回分以下なら 6 分の 1、それより多ければ 0 とする。枠が余る日は新規で埋める。固定の割合で新規を入れ続けると、1 問の新規が数回分の復習を生むので、復習待ちが際限なく増える。

この規則は実測ではなく、記憶の減衰モデルと実コードのシミュレーションで候補を比べて決めた（2026-11-05）。覚えた語数の絶対値は参考にならない。新規が出ない日の割合は仮定で大きく変わり、モデルでは 27%、全問の正答率を一定とする悲観的な条件では 75% だった。利用データが溜まったら、`attempt_items` の実績で検証する。

## 実力診断

語彙の空所補充を 10 問ずつ、準2級、2級の基本（難度 1）、2級の応用（難度 2〜3）の 3 段で出す。段は、正解数から誤答数の 1/3 を引いた点が 7 以上で通過し、通過できなかった段で打ち切る。最大 30 問で、通過した段の数が段階（0〜3）になる。

| 段階 | 日課の新しい問題 | 長文 |
|---|---|---|
| 0 | 準2級 → 2級の難度 1 → それ以外 | 日課に入れない |
| 1 | 2級の難度 1 → それ以外 | 2 日に 1 回 |
| 2、未受験 | 2級全体から無作為 | 2 日に 1 回 |
| 3 | 2級の難度 2〜3 → それ以外 | 2 日に 1 回 |

- 診断の解答は復習の履歴に入れない。入れると、苦手な学習者ほど誤答で復習待ちが埋まり、最初の日課が復習だけになる。
- 語彙だけを測る。文法と長文は測っていない。
- 問題数と合格点は、仮想の学習者 6 種類のシミュレーションで決めた（各段 10 問、合格 7 点で平均 81% が正しい段階。12 問でも 82%）。学習者像と問題の難度はどちらも仮定で、実データでの校正はしていない。
- 段階は問題の順番と長文の有無を変えるだけで、「形式を選んで解く」は制限しない。受け直しはいつでもでき、結果は上書きされる。
